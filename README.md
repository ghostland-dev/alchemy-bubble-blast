# Alchemy Bubble Blast

Browser bubble-shooter game with an alchemy theme.

## Features

- Canvas-style gameplay in React
- Score tracking

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/alchemy-bubble-blast.git
cd alchemy-bubble-blast
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
